# 🎬 Voice Lock for Storytelling - START HERE

## 📖 What Is This?

This is a **complete voice-locking system** for creating consistent character voices across multiple scenes in **Veo 3.1** using only prompt engineering — no external tools required.

---

## 🎯 The Problem It Solves

**Problem**: When you generate multiple scenes for a story in Veo 3.1, each character's voice sounds different because Veo processes each prompt independently with no memory of previous scenes.

**Solution**: Lock the voice by using **identical Voice Anchor Blocks** in every scene, ensuring Veo generates the same voice characteristics every time.

**Result**: Professional storytelling with consistent character voices across unlimited scenes.

## 🎭 The 3-Lock System (Core Concept)

### **Lock #1: Voice Anchor Block**
A 50-80 word description of the character's voice that you copy-paste into EVERY scene.

**Example**:
```
Aria, a woman in her late 20s, with a clear, determined alto voice, 
steady and purposeful tone, soft Irish accent, speaks with quiet 
courage and underlying vulnerability, as if carrying a great burden.
```

---

### **Lock #2: Audio Environment**
The technical audio settings that stay identical for each character.

**Example**:
```
Close-mic, clean audio, warm tone, no reverb
```

---

### **Lock #3: Ambient Sound**
Location-specific background sounds that stay consistent per location.

**Example**:
```
Ambient sound: rustling leaves, distant bird calls, wind through branches
```

---

## 📝 Scene Prompt Template

```
[SHOT TYPE]. [VOICE ANCHOR BLOCK]. [ACTION]. [DIALOGUE]. 
[AUDIO ENVIRONMENT]. [AMBIENT SOUND]. [VISUAL STYLE]. No subtitles.
```

**Copy this structure for every scene. Only change the action and dialogue.**

- [ ] Each prompt makes sense standalone

## 🎬 Example: 3-Scene Story

### **Character Voice Anchor** (used in ALL 3 scenes):
```
Elena, a woman in her early 30s, with a smooth, warm alto voice, 
confident and unhurried tone, soft neutral American accent, speaks 
with a calm, reassuring presence.
```

### **Audio Environment** (used in ALL 3 scenes):
```
Close-mic, clean audio, warm tone, no reverb
```

---

**Scene 1**:
```
Wide shot. Elena, a woman in her early 30s, with a smooth, warm alto 
voice, confident and unhurried tone, soft neutral American accent, 
speaks with a calm, reassuring presence. She stands in an ancient 
library, holding a glowing artifact. She says: "This changes 
everything we thought we knew." Close-mic, clean audio, warm tone, no 
reverb. Ambient sound: rustling pages, distant footsteps, old wood 
creaking. Warm candlelight, dramatic shadows. No subtitles.
```

**Scene 2**:
```
Close-up. Elena, a woman in her early 30s, with a smooth, warm alto 
voice, confident and unhurried tone, soft neutral American accent, 
speaks with a calm, reassuring presence. She examines ancient text, 
eyes widening. She says: "The prophecy wasn't a warning. It was an 
invitation." Close-mic, clean audio, warm tone, no reverb. Ambient 
sound: rustling pages, distant footsteps, old wood creaking. Warm 
candlelight on face. No subtitles.
```

**Scene 3**:
```
Medium shot. Elena, a woman in her early 30s, with a smooth, warm alto 
voice, confident and unhurried tone, soft neutral American accent, 
speaks with a calm, reassuring presence. She closes the book with 
determination. She says: "I know what I have to do now." Close-mic, 
clean audio, warm tone, no reverb. Ambient sound: rustling pages, 
distant footsteps, old wood creaking. Warm candlelight, resolved 
expression. No subtitles.
```

**Notice**: The Voice Anchor Block is IDENTICAL in all 3 scenes. Only the action and dialogue changed.

## 💡 Key Principles

### **The Golden Rule**
> **Lock what defines the voice. Vary what tells the story.**

**Locked**:
- Voice Anchor Block
- Audio Environment
- Ambient Sound (per location)

**Variable**:
- Shot type
- Action
- Dialogue
- Emotion

---

### **The Consistency Formula**
```
Exact Repetition = Consistent Output
```

If you copy-paste the Voice Anchor Block word-for-word, Veo will generate the same voice.

---

### **The Standalone Principle**
> **Each prompt must make sense without knowing other scenes.**

Never reference "Scene 1" or "previous scene". Each prompt is processed independently.
