# Complete Consistency System: Visual + Voice Lock

## 🎯 The Dual-Lock System for Veo 3.1 Storytelling

This document combines **Visual Consistency** (from Standalone_Prompts_Veo.md) with **Voice Consistency** (Voice Lock) for complete character continuity across story scenes.

---

## 🔐 Two Independent Lock Systems

### **Lock System 1: Visual Consistency**
**Purpose**: Keep character appearance identical across scenes  
**Method**: Ultra-specific 12-parameter character description  
**Key**: Copy-paste complete visual description

### **Lock System 2: Voice Consistency**
**Purpose**: Keep character voice identical across scenes  
**Method**: Voice Anchor Block with audio environment  
**Key**: Copy-paste complete voice description

---

## 📋 Complete Character Profile Template

For each character in your story, create BOTH profiles:

### **Character: [Name]**

#### **Visual Anchor Block** (150-200 words)
```
A [gender] with [skin tone] and [texture], [eye color] [eye shape] 
eyes conveying [expression], [eyebrow characteristics], [nose features], 
[mouth/lip appearance], [facial hair]. [Face shape] with [structure]. 
[Hair/headwear details]. [Clothing colors and style with specific 
details]. [Jewelry and ornaments with counts and positions]. 
[Distinctive marks]. [Body build] with [posture].
```

**12 Required Parameters:**
1. Skin tone and texture
2. Eye color, shape, and expression
3. Eyebrow characteristics
4. Nose features
5. Mouth/lip appearance
6. Facial hair
7. Face shape and structure
8. Hair/headwear details
9. Clothing colors and style
10. Jewelry and ornaments
11. Distinctive marks
12. Body build and posture

---

#### **Voice Anchor Block** (50-80 words)
```
[Name], a [age range], with a [vocal quality] voice, [speaking style] 
tone, [accent], speaks with [emotional baseline].
```

**5 Required Elements:**
1. Age range
2. Vocal quality
3. Speaking style
4. Accent/origin
5. Emotional baseline

---

#### **Audio Environment**
```
[Mic position], [audio quality], [tone], [reverb setting]
```

## 📝 Complete Scene Prompt Structure

### **Full Template**

```
[SHOT TYPE]. [VISUAL ANCHOR BLOCK]. [VOICE ANCHOR BLOCK]. [ACTION]. 
[DIALOGUE]. [AUDIO ENVIRONMENT]. [AMBIENT SOUND]. [VISUAL STYLE]. 
No subtitles.
```

### **Component Breakdown**

| Component | Purpose | Consistency Rule |
|-----------|---------|------------------|
| **Shot Type** | Visual framing | Varies per scene |
| **Visual Anchor Block** | Character appearance | IDENTICAL across scenes |
| **Voice Anchor Block** | Character voice | IDENTICAL across scenes |
| **Action** | What character does | Varies per scene |
| **Dialogue** | What character says | Varies per scene |
| **Audio Environment** | Technical audio | IDENTICAL per character |
| **Ambient Sound** | Location atmosphere | IDENTICAL per location |
| **Visual Style** | Lighting/camera | Consistent per story |
| **No Subtitles** | Subtitle setting | IDENTICAL across scenes |

## ✅ Complete Consistency Checklist

Before generating each scene, verify:

### **Visual Lock**
- [ ] All 12 visual parameters present
- [ ] Exact same wording as previous scenes
- [ ] Specific colors (not "dark" or "light")
- [ ] Precise counts (three buttons, two braids, etc.)
- [ ] Unique identifiers (scar, pendant, embroidery pattern)

### **Voice Lock**
- [ ] All 5 voice elements present
- [ ] Exact same wording as previous scenes
- [ ] Age range unchanged ("late 20s" not "around 30")
- [ ] Accent description identical
- [ ] Speaking style unchanged

### **Audio Lock**
- [ ] Audio environment word-for-word identical
- [ ] Ambient sound matches location
- [ ] No vague audio descriptors

### **Standalone Quality**
- [ ] No scene references ("Scene 1", "previous scene")
- [ ] Prompt makes sense without context
- [ ] Complete description (visual + voice)
- [ ] 300-400 words total

## 🎯 Why This Works

### **Visual Consistency**
Veo generates the same appearance because it sees the **exact same visual description** every time.

### **Voice Consistency**
Veo generates the same voice because it sees the **exact same voice description** every time.

### **Combined Effect**
Character looks AND sounds identical across all scenes = **perfect continuity**.

## 💡 Pro Tips

### **Tip 1: Create Character Cards**
Save each character's complete profile (visual + voice) in a document for easy copy-paste.

### **Tip 2: Verify Before Generating**
Compare Scene 2's character description to Scene 1 character-by-character before generating.

### **Tip 3: Test Scene 1 First**
Generate Scene 1, verify both appearance and voice are correct, then proceed with remaining scenes.

### **Tip 4: Batch Prepare**
Write all scene prompts with locked descriptions before generating any videos.

### **Tip 5: Location Grouping**
Generate all scenes in the same location together to maintain ambient sound consistency.

## 🔧 Troubleshooting

### **Problem: Character looks different between scenes**
**Diagnosis**: Visual Anchor Block has variations  
**Fix**: Compare visual descriptions word-for-word, find differences, make identical

### **Problem: Character sounds different between scenes**
**Diagnosis**: Voice Anchor Block has variations  
**Fix**: Compare voice descriptions word-for-word, find differences, make identical

### **Problem: Audio quality inconsistent**
**Diagnosis**: Audio environment descriptor varies  
**Fix**: Use exact same audio environment phrase in all scenes

### **Problem: Character looks/sounds too robotic**
**Diagnosis**: Descriptions too rigid or neutral  
**Fix**: Add natural elements:
- Visual: "slight smile", "eyes narrowed", "hair slightly windswept"
- Voice: "pausing between phrases", "voice rising at sentence end"
