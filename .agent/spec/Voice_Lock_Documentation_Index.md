## ✅ Master Checklist

Before starting ANY story generation project:

### **Planning Phase**
- [ ] Read relevant documentation (see Reading Path above)
- [ ] Outline story structure (number of scenes, locations)
- [ ] List all characters
- [ ] Decide on visual + voice or voice-only consistency

### **Character Creation Phase**
- [ ] Create Voice Anchor Block for each character (50-80 words)
- [ ] Create Visual Anchor Block if using dual-lock (150-200 words)
- [ ] Choose Audio Environment for each character
- [ ] Save character profiles for copy-paste

### **Location Planning Phase**
- [ ] List all locations in story
- [ ] Define Ambient Sound for each location
- [ ] Ensure consistency (same location = same ambient sound)

### **Prompt Writing Phase**
- [ ] Write all scene prompts before generating
- [ ] Copy-paste Voice Anchor Blocks (word-for-word)
- [ ] Copy-paste Visual Anchor Blocks if using dual-lock
- [ ] Verify audio environment is identical per character
- [ ] Verify ambient sound matches location
- [ ] No scene references ("Scene 1", "previous scene")

### **Pre-Generation Phase**
- [ ] Run Pre-Generation Checklist (Voice_Lock_Quick_Reference.md)
- [ ] Compare Scene 2 to Scene 1 character descriptions
- [ ] Verify all locks are word-for-word identical
- [ ] Test Scene 1 first before generating all scenes

### **Generation Phase**
- [ ] Generate Scene 1
- [ ] Verify voice quality and character appearance
- [ ] If good, proceed with remaining scenes
- [ ] If issues, troubleshoot and regenerate Scene 1

## 💡 Key Principles (From All Documents)

### **The Golden Rule**
> **Lock what defines the voice. Vary what tells the story.**

### **The 3-Lock System**
1. **Voice Anchor Block** - Character voice identity
2. **Audio Environment** - Technical consistency
3. **Ambient Sound** - Location atmosphere

### **The Consistency Formula**
```
Exact Repetition = Consistent Output
```

### **The Standalone Principle**
> **Each prompt must make sense without knowing other scenes.**
