# Voice Lock Quick Reference Card

## 🎯 The 3-Lock System for Storytelling

### **Lock #1: Voice Anchor Block**
```
[Name], a [age range], with a [vocal quality] voice, [speaking style] 
tone, [accent], speaks with [emotional baseline].
```

**Required Elements:**
- Age range (not exact age)
- Vocal quality (deep, bright, raspy, smooth, etc.)
- Speaking style (slow, quick, measured, animated, etc.)
- Accent/origin (British, Southern, neutral, etc.)
- Emotional baseline (confidence, warmth, intensity, etc.)

**Rule**: Copy-paste WORD-FOR-WORD into every scene with this character.

---

### **Lock #2: Audio Environment**
```
Close-mic, clean audio, warm tone, no reverb
```

**Common Options:**
- **Intimate**: Close-mic, clean audio, warm tone, no reverb
- **Outdoor**: Natural outdoor audio, slight wind ambience, clear voice
- **Indoor**: Room tone, slight acoustic warmth, natural reverb
- **Dramatic**: Studio-quality audio, deep presence, controlled dynamics
- **Whispered**: Close-mic, hushed tone, minimal room noise

**Rule**: Use IDENTICAL descriptor for same character across all scenes.

---

### **Lock #3: Ambient Sound**
```
Ambient sound: [location-specific sounds]
```

**By Location:**
- **Forest**: rustling leaves, distant bird calls, wind through branches
- **Temple**: echoing footsteps, distant chanting, stone acoustics
- **Mountain**: howling wind, distant thunder, echoing silence
- **City**: distant traffic, footsteps on pavement, urban ambience
- **Cave**: echoing drips, hollow acoustics, subtle reverb
- **Castle**: crackling torches, distant footsteps, stone hall echo
- **Ocean**: crashing waves, seagull cries, wind over water
- **Spaceship**: humming engines, beeping consoles, air circulation

**Rule**: Use IDENTICAL ambient sound for scenes in same location.

## 📝 Scene Prompt Template

```
[SHOT TYPE]. [VOICE ANCHOR BLOCK]. [ACTION]. [DIALOGUE]. 
[AUDIO ENVIRONMENT]. [AMBIENT SOUND]. [VISUAL STYLE]. No subtitles.
```

### **Shot Types**
- Wide shot
- Medium shot
- Close-up
- Medium two-shot (for dialogue)
- Over-the-shoulder
- Extreme close-up

### **Action Format**
```
[Character] [action verb] [specific details]. [Physical description].
```

### **Dialogue Format**
```
[Character] says: "[dialogue]"
[Character] responds: "[dialogue]"
[Character] whispers: "[dialogue]"
[Character] shouts: "[dialogue]"
```

### **Visual Style**
```
[Lighting description], [atmosphere], [camera movement]
```

- [ ] Ambient Sound defined per location
- [ ] Voice Anchor Block saved for copy-paste
- [ ] No scene references ("Scene 1", "previous scene")
- [ ] Each prompt is standalone

---

## 🚫 Common Mistakes to Avoid

❌ **DON'T:**
- Change wording in Voice Anchor Block between scenes
- Reference "Scene 1" or "previous scene"
- Use vague descriptors ("dark voice", "nice tone")
- Leave audio/ambient to default
- Add multiple emotion modifiers per scene

✅ **DO:**
- Copy-paste Voice Anchor Block exactly
- Make each prompt 100% standalone
- Use specific descriptors ("gravelly baritone", "warm alto")
- Always specify audio environment and ambient sound
- Use ONE emotion modifier per scene

## 🎬 Example: 3-Scene Story

### **Character Voice Anchor** (used in ALL scenes):
```
Elena, a woman in her early 30s, with a smooth, warm alto voice, 
confident and unhurried tone, soft neutral American accent, speaks 
with a calm, reassuring presence.
```

### **Audio Environment** (used in ALL scenes):
```
Close-mic, clean audio, warm tone, no reverb
```

---

**Scene 1: The Discovery**
```
Wide shot. Elena, a woman in her early 30s, with a smooth, warm alto
```

```
Close-up. Elena, a woman in her early 30s, with a smooth, warm alto

```

## 💡 Quick Tips

1. **Save Voice Anchors**: Keep in a text file for easy copy-paste
2. **One Emotion Per Scene**: "speaks with confidence" not "confidence, fear, and hope"
3. **Location = Ambient Sound**: Same location = same ambient sound
4. **Test Scene 1 First**: Verify voice before generating all scenes
5. **Batch Prepare**: Write all prompts before generating videos

---

## 🔧 Troubleshooting

**Voice sounds different?**
→ Compare Voice Anchor Blocks character-by-character. Find the difference.

**Voice sounds robotic?**
→ Add natural speech patterns: "pausing between phrases", "voice rising at sentence end"

**Characters sound too similar?**
→ Make Voice Anchor Blocks MORE different (age, accent, tone, style)
